# Damascus Emergency Inventory — Windows Portable `3.0.1`

هذه حزمة Windows Portable من نظام مستودع الإسعاف والطوارئ — دمشق.

## الملف

- `Damascus Emergency Inventory 3.0.1.exe` — تطبيق Windows Portable
- `SHA256SUMS` — مجموع التحقق من سلامة الملف

## التشغيل

1. نزّل ملف EXE إلى جهاز Windows.
2. شغّل الملف مباشرة؛ لا يحتاج إلى مثبت منفصل.
3. تعمل النسخة بقاعدة بيانات محلية داخل مجلد بيانات التطبيق.

## محتوى الإصدار

- رقم الإصدار: `3.0.1`
- مبني من آخر نسخة من الفرع `main`.
- يتضمن واجهة التطبيق المسجلة بالإصدار `v3.0.1`.
- يتضمن خادم API المحلي وقاعدة PGlite المضمّنة اللازمة للتشغيل المستقل.
