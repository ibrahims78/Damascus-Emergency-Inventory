# Damascus Emergency Inventory — Android v2.0.5

نسخة Android offline مبنية من الفرع `main`.

## تفاصيل الإصدار

- **Version name:** `2.0.5`
- **Version code:** `205`
- **Application ID:** `syrian.emergency.inventory`
- **Build type:** Release
- **Storage:** IndexedDB محلي داخل الجهاز

## إصلاح الاستعادة

يعالج هذا الإصدار استعادة حزم `.dme-sync` الكاملة على Android offline:

- دعم كل كيانات المخزون والحركات والدفعات والعهد والتلف والمرتجعات.
- إعادة ربط مراجع المستخدمين غير الموجودة بالمستخدم الحالي بدلاً من تركها مكسورة.
- تحديث عدّاد المعرفات بعد إدخال معرفات صريحة من النسخة الاحتياطية.
- الإبقاء على الفحص والمعاينة والتأكيد الصريح قبل التطبيق.

## التحقق

ملف `SHA256SUMS` يثبت سلامة ملف APK بعد نقله أو تنزيله.
