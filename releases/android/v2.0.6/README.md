# Damascus Emergency Inventory — Android v2.0.6

نسخة Android offline مبنية من الفرع `main`.

## تفاصيل الإصدار

- **Version name:** `2.0.6`
- **Version code:** `206`
- **Application ID:** `syrian.emergency.inventory`
- **Build type:** Release
- **Storage:** IndexedDB محلي داخل الجهاز

## إصلاح الاستعادة

يعالج هذا الإصدار مشكلة بقاء شاشة استعادة النسخة الاحتياطية في حالة Dry Run على Android:

- حفظ معاينة الاستعادة محلياً في IndexedDB بدلاً من الاعتماد على ذاكرة صفحة WebView فقط.
- إمكانية متابعة التأكيد بعد إعادة إنشاء الصفحة أو WebView دون فقدان المعاينة.
- دعم كيانات المخزون والحركات والدفعات والعهد والتلف والمرتجعات ومراجع المستخدمين كما في الإصدار السابق.
- تحديث عداد المعرفات بعد إدخال معرفات صريحة من النسخة الاحتياطية.

## التحقق

ملف `SHA256SUMS` يثبت سلامة ملف APK بعد نقله أو تنزيله.
