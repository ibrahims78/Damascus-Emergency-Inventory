# Damascus Emergency Inventory — Android v2.0.4

نسخة Android offline كاملة مبنية من الفرع `main`.

## تفاصيل الإصدار

- **Version name:** `2.0.4`
- **Version code:** `204`
- **Application ID:** `syrian.emergency.inventory`
- **Build type:** Release
- **Storage:** IndexedDB محلي داخل الجهاز

## إصلاح الاستعادة

يعالج هذا الإصدار استعادة ملفات `.dme-sync` المشفرة بعد الفحص والمعاينة، بما في ذلك الأجهزة التي تستخدم قاعدة IndexedDB قديمة. تمت المحافظة على الفحص، المعاينة، التأكيد الصريح، والاستعادة الذرية دون الحاجة إلى API أو PostgreSQL.

## التشغيل

ثبّت ملف `Damascus-Emergency-Inventory-v2.0.4-offline.apk` على Android. كلمة مرور ملف الاختبار المرفق: `12345678`.

## التحقق

ملف `SHA256SUMS` يثبت سلامة ملف APK بعد نقله أو تنزيله.
