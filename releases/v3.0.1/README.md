# Damascus Emergency Inventory — Android Offline `3.0.1`

هذه حزمة Android Offline جديدة من نظام مستودع الإسعاف والطوارئ — دمشق.

## الملف

- `damascus-emergency-inventory-offline-v3.0.1.apk` — حزمة Android Release
- `SHA256SUMS` — مجموع التحقق من سلامة الملف

## التثبيت

1. نزّل ملف APK إلى جهاز Android.
2. فعّل السماح بتثبيت التطبيقات من هذا المصدر عند الطلب.
3. ثبّت التطبيق وافتحه.

تعمل هذه النسخة محليًا باستخدام قاعدة IndexedDB داخل الجهاز، ولا تحتاج إلى
واجهة API أو PostgreSQL أو اتصال بخادم خارجي أثناء التشغيل غير المتصل.

## محتوى الإصدار

- رقم الإصدار: `3.0.1`
- رقم البناء: `301`
- مبني من آخر نسخة من الفرع `main`.
- يتضمن إصلاحات دورة حياة العهدة والعمل المحلي دون API.
- يتضمن أحدث أصول واجهة الويب المضمنة داخل تطبيق Capacitor.

> إعداد التوقيع بمفتاح إصدار خاص محفوظ خارج المستودع.
